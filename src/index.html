About OWASP FIASSE

Framework for Integrating Application Security Software Engineering

What is FIASSE?

FIASSE (Framework for Integrating Application Security Software Engineering) is an OWASP project that provides a comprehensive approach to building secure software applications.

It combines practical security methodologies with modern software engineering practices to create a framework that is both effective and implementable in real-world scenarios.

Our Mission

To provide developers and security professionals with practical, actionable frameworks for integrating security into every phase of the software development lifecycle.

We believe security should be relentlessly practical and relentlessly securable - embedded naturally into development processes rather than bolted on as an afterthought.

Core Principles

Practical Implementation

Focus on real-world applicability with tools and processes that developers can immediately implement in their workflows.

Continuous Security

Integrate security considerations throughout the entire development lifecycle, not just at the end.

Measurable Outcomes

Provide clear metrics and assessment tools to measure security posture and improvement over time.
