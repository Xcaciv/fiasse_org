About OWASP FIASSE

Framework for Integrating Application Security Software Engineering

What is FIASSE?

FIASSE (Framework for Integrating Application Security Software Engineering) is an OWASP project that provides a comprehensive approach to building secure software applications.

It combines practical security methodologies with modern software engineering practices to create a framework that is both effective and implementable in real-world scenarios.

Our Mission

To provide developers and security professionals with practical, actionable frameworks for integrating security into every phase of the software development lifecycle.

We believe security should be relentlessly practical and relentlessly securable - embedded naturally into development processes rather than bolted on as an afterthought.

Core Principles

Practical Implementation

Focus on real-world applicability with tools and processes that developers can immediately implement in their workflows.

Continuous Security

Integrate security considerations throughout the entire development lifecycle, not just at the end.

Measurable Outcomes

Provide clear metrics and assessment tools to measure security posture and improvement over time.

What is SSEM?

The foundation of securable software engineering

The Securable Software Engineering Model (SSEM) is a systematic approach to building secure software that integrates security considerations at every stage of the development process. Unlike traditional approaches that treat security as an add-on, SSEM embeds security into the fundamental fabric of software engineering practices.

Core Principles

  • Security by Design:

    Security considerations from the earliest design phases

  • Continuous Assessment:

    Ongoing security evaluation throughout development

  • Risk-Driven Approach:

    Prioritizing efforts based on actual risk assessments

Key Benefits

  • Reduced Vulnerabilities:

    Early detection and prevention of security issues

  • Cost Efficiency:

    Lower costs through early security integration

  • Compliance Ready:

    Built-in compliance with security standards

Proactive Security

SSEM shifts from reactive security patching to proactive security engineering, preventing vulnerabilities before they occur.

Developer-Centric

Designed to integrate seamlessly with existing development workflows without disrupting productivity.

Scalable Framework

Adaptable to projects of any size, from small applications to enterprise-scale systems.
